# Amplify — Publishing Guide

## Chrome Web Store

1. Go to https://chrome.google.com/webstore/devconsole
2. Click "New Item" → upload `amplify-chrome-v2.1.0.zip`
3. Fill in:
   - **Name:** Amplify
   - **Description:** paste from `chrome-description.txt`
   - **Category:** Productivity
   - **Language:** English
   - **Privacy policy URL:** https://github.com/Harisathwik/amplify/blob/master/PRIVACY.md
   - **Single purpose:** Volume boost and audio enhancement for browser tabs
   - **Permission justifications:**
     - storage: Store user volume/EQ preferences locally
     - contextMenus: Provide right-click volume controls
     - tabs: Display list of tabs currently playing audio
4. Upload 5 screenshots (1280x800)
5. Upload store icon (128x128 — use `icons/icon-128.png`)
6. Submit for review (1-3 days)

## Firefox Add-ons (AMO)

1. Go to https://addons.mozilla.org/developers/
2. Click "Submit a New Add-on"
3. Upload `amplify-firefox-v2.1.0.zip`
4. Fill in:
   - **Name:** Amplify
   - **Summary:** Volume boost up to 600% that works in fullscreen
   - **Description:** paste from `chrome-description.txt`
   - **Category:** Other
   - **License:** MIT
   - **Homepage:** https://github.com/Harisathwik/amplify
   - **Support email:** (your email)
5. Upload screenshots
6. Submit (1-5 days review)

## Edge Add-ons

1. Go to https://partner.microsoft.com/dashboard/microsoftedge
2. Sign in with Microsoft account
3. Click "New Extension" → upload `amplify-chrome-v2.1.0.zip` (same file)
4. Fill in:
   - **Name:** Amplify
   - **Description:** paste from `edge-description.txt`
   - **Category:** Productivity
   - **Privacy policy:** same GitHub URL
5. Upload screenshots
6. Submit (1-7 days review)

## Screenshots to Take

1. Popup at 200% on YouTube (blue slider fill, "2x" badge)
2. Night mode + normalize ON (visualizer active)
3. Site profile saved ("Auto-saving for youtube.com")
4. Tab audio list (2+ tabs with audio)
5. YouTube fullscreen working (proves the core feature)

Resize browser to 1280x800 for consistent screenshots.
